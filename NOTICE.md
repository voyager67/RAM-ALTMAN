# Project notice

RAM Sentinel is a parody utility. It is not affiliated with, endorsed by, or operated by OpenAI or Sam Altman.

The script does not contain a hard-coded recipient address. Operators must configure their own recipient and sender, or an optional HTTPS webhook. Use a recipient who has explicitly agreed to receive parody messages.

The project premise was inspired by [Iain Kay's ram-altman repository](https://github.com/IainKay/ram-altman), released under The Unlicense. RAM Sentinel is a separate implementation.
